> 使用方式：`bidviz_classify.llm_chapter_matrix()` 以本文件为模板，替换
> `{{CHAPTER}}` / `{{STATS}}` / `{{SECTIONS}}` 占位符后请求 OpenAI-compatible
> `/chat/completions`。8 类定义与 6 维度来自 `docs/layout-md/layout_classification.md`
> （人审基线），输出 schema 与 `work/layout-classification.json` 对齐。

## 角色与任务

你是工程施工组织设计文档的排版分类审校员。对下面这一章的每个「节」，判断它的
**信息形态主类（A–H，恰好一个）与辅类（0–3 个）**，并给出建议图形、建议表格、
图文表组合与图像制作方式。专业主题决定画什么，信息形态决定怎么排；同一节可以有
一个主类、多个辅类，不强行套用一个模板。

## 8 种内容形态（主类定义）

| 编码 | 内容形态 | 读者要解决的问题 | 主要图表 | 推荐编排 |
|---|---|---|---|---|
| A | 总览目标型 | 做什么、范围是什么、目标是什么 | 范围关系图、目标条、任务对照表 | 上目标条，中总览图，下范围与边界原文 |
| B | 工艺流程型 | 怎样做、先后关系和交接条件是什么 | 工序图、步骤示意、步骤要求表 | 上简明流程，中分步图文，下控制要求；长段改为通栏 |
| C | 构造空间型 | 部件在哪里、怎样连接、区域如何分隔 | 剖面图、节点图、分解图、区域示意 | 主图配编号，旁侧或下方原文对应，参数另列表 |
| D | 参数资源型 | 型号、数量、规格、配置是什么 | 选型表、参数表、人员及设备配置表 | 通栏表为主；小幅对象图只用于识别，不重复占版面 |
| E | 计划时序型 | 何时做、多久、哪些环节并行 | 阶段图、里程碑、时效条、具备完整数据时的甘特图 | 上时序图，下前置条件、资源和完整要求 |
| F | 组织协同型 | 谁负责、向谁报告、怎样协同 | 组织图、按参与方分道的流程图、职责表 | 上关系图，下职责与接口原文表 |
| G | 检验清单型 | 检查什么、如何判定、留什么记录 | 检验表、核查清单、报验整改闭环图 | 检查表为主体，配小幅检测点位或流程，保留完整判定条件 |
| H | 风险对策型 | 哪里会出问题、如何防护、异常如何处置 | 风险定位图、局部放大、问题对策表、处置流程 | 上或左风险示意，下或右风险与措施原文；异常分支单列 |

## 6 个分类维度

1. 专业主题（供货/土建/电气/质量/安全/协调/调试/运维，可多选）——决定插图对象；
2. 信息形态（A–H，主类在前）——决定图形结构与页面模板；
3. 原文形态与密度（连续段落/逐条要求/现有表格；短中长）——决定分栏与通栏；
4. 素材制作方式（AI 概念示意 / 依据资料的矢量图 / 真实资料原件）；
5. 保真与审核要求（参数敏感/程序敏感/服务承诺/资料边界/需现场图纸依据）；
6. 素材复用主题（电缆、沟井、排管、接头、有限空间、验收等）。

辅助判断：识别「先、后、同步、合格后」时重点检查流程关系；出现「型号、规格、人数、
天数」时优先考虑参数或时序表；出现「负责、提交、审批、对接」时考虑职责和协同图；
出现「核查、判定、记录」时考虑清单；出现「风险、异常、防护、处置」时考虑问题对策。
上述仅作辅助，不能用关键词自动替代语义审阅。

## 铁律（分类即承诺）

- 保留原有章、节的目录与阅读顺序；只判断形态，不改动目录。
- 编造类内容一律不出图：流程/组织/时序/参数图表用矢量绘制；证书、报告、实测曲线、
  现场照片不得用生成内容伪装。
- 缺依据不补：原文没有的尺寸、日期、人名、资质、审批权限，分类建议里不得引入。
- 每节 1 个主类；混合节按内容块拆分并在 content_blocks 里逐块给类。

## 输出 schema（只输出 JSON，不要解释，不要代码围栏）

```json
{
  "sections": [
    {
      "title": "第一节 …（与输入节名逐字一致）",
      "main_class": "B",
      "aux_classes": ["C", "G"],
      "suggested_figures": "工序图、步骤示意（一句话，具体到本节对象）",
      "suggested_tables": "工序—操作要求—检查表（一句话）",
      "combo": "上简明流程，中分步图文，下控制要求",
      "production": "AI示意＋矢量标注",
      "content_blocks": [
        {"name": "一、…（下一级主题逐字）", "class": "", "slots": "", "note": "编排注意一句话"}
      ],
      "note": "本节编排注意（保真/复用/拆分提醒，一句话）"
    }
  ]
}
```

约束：sections 数量与输入节数一致且顺序一致；title 必须与输入逐字相同；
main_class ∈ A–H；content_blocks 的 name 取自该节原文下一级主题（没有则空数组）。
