根因：该模型画的是「像汉字的形状」，不是排版真字。常用字它记住了，笔画复杂的字就编一个「正确偏旁 + 编造的另一半」。所以加「不要错别字」的约束无效 —— 它没有查字机制。

唯一可靠路线：图内零文字，全部文字由矢量层叠加。
这正是最初定的 hybrid overlay 架构，我在写提示词时违背了它。

要改的地方：
1. 生图提示词改为「零文字硬约束」（已验证有效）
2. 图片只承担视觉，所有标注/尺寸/说明由 bidviz_vector.py 矢量叠加
3. 图旁加矢量图注说明分层顺序（如「自上而下：盖板 / 钢筋骨架 / 沟壁 / 垫层 / 基底」），不做虚假的定位引线
