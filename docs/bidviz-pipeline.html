01 · 解析 ingest

把 Word/PDF 解析成结构化块。每个块保留来源页、章节路径与 sha256，可反查原文。

输入：.docx / .pdf输出：blocks.json命令：bidviz ingest anke-35kv
产物内容
blocks.json每块：block_id、source_page、kind（heading/body）、section_path、text、sha256
pages.json按页聚合的块索引
page-media-map.json源文档每页的内嵌图片清单（参考图/素材来源）
这是唯一写原文的环节。后续所有编辑都不改 blocks.json，而是通过 edits.json 投影。

02 · 分类 classify

对每一节判断 8 类内容形态（A–H）与建议图表，形成人审版 markdown + 机读 json。

输入：blocks.json输出：layout-classification.json / classification.md门禁：五字段 / 节覆盖 / 原起始页单调
类内容形态主图
A总览目标型范围关系图、目标条
B工艺流程型工序图、步骤示意
C构造空间型剖面图、节点图
D参数资源型选型表、参数表
E计划时序型阶段图、里程碑
F组织协同型组织图、职责表
G检验清单型检验表、核查清单
H风险对策型风险定位图、对策表
分类决定模板与 KPI 数量。安科项目 57 节主类已人工审过；总述节 S001 走封面专用通道。

03 · 页规划 page-plan

把分类结果转成每节的内容槽位：KPI、保留正文、表格、页数预算（≤3 页/节）。

规则内容
KPI 数量（D12）A/B ≤3；C/E/H 1–2；D/F/G = 0
KPI 优先级工期 > 工程量 > 关键型号；只取原文真实数值
保留段（D3）A/B/C 保留 1–2 段关键原文；H 保留条件句；D/E/F/G 全表
表格施工工序 / 参数与指标 / 风险与控制要求 / 材料与设备
页数预算每节 ≤3 页，超出记 overflow
输入：分类 + blocks输出：work/page-plan.json代码：src/bidviz_plan.py

04 · 语义分页

先按一级主题（一、二、三…）成组，主题过长再按二级标题（（一）（二）…）拆；每页标记本页实际主题，续页不写“（续）”。

分页规则

  • 一级主题优先成组，不拆散可完整放下的主题
  • 单主题 >1500 字 → 按二级标题拆
  • 仍过长 → 按段落边界拆
  • 总页数 ≤3，块顺序不变、每块只出现一次

页主题示例（S002）

页页面主题
P1一、35kV主用电源电缆选型 / （一）电缆品牌选定范围
P2二、高压专项测试型式报告 / （一）国家级第三方检测机构出具报告
P3三、成品外护套标识 / 四、电缆装卸运输防护
历史问题：旧版每页固定使用本节第一个三级标题，导致多页节标题重复。已由 page_topic 修复。

07 · 论文审计（自动门禁）

每张候选图生成后先过自动检查，再进入人工审阅。阻断项不自动发布。

检查标准
文件完整性PNG 可解码、非空
尺寸/方向宽 ≥2048；竖版；比例接近 A3（±0.035）
参考图正文页 reference_count ≥1；封面页为 0
AI 页码OCR 不得出现 1/3、第N页、—N—
编造署名不得出现设计单位/审核人/日期/图号
关键串标题、KPI 数值、型号、单位、条件句逐字命中
普通正文首/中/尾抽样；≥2 处缺失 → block
自动门禁只决定能否进入人工审阅，不能代替人工批准。Web 工作台的候选审阅/发布/回滚走 bidviz_fullimage_store.py。

（一）电缆沟井排管土方开挖作业实施
沿已完成测量放线定位的作业边界开展普通土开挖作业，控制开挖深度在2 至3 米区间 内，严格对齐电缆沟、工井、排管的设计作业面位置。选用斗容0.3m³的履带式挖掘机主导 开挖作业，开挖过程中预留150mm 厚的基底土层由人工清理找平，避免机械扰动基底原状土， 保证基底承载力符合设计要求。
开挖作业同步跟进坡面防护前置措施，作业面挖出一段即清理一段坡面浮土，为后续挂 网喷C25 混凝土60 厚的放坡支护工序预留充足作业空间，坡面坡度全程按规范要求控制， 随时排查边坡开裂、滑移风险。开挖产生的临时堆土沿沟槽边缘安全距离外有序堆放，避免 堆载过量挤压边坡造成垮塌隐患。
（二）分层回填土作业实施
回填作业在电缆沟、工井主体结构及排管包封混凝土强度达到设计要求后启动，清理作 业面内的积水、杂物与建筑垃圾，确认回填范围内无外露锐边硬物破坏作业面防护层。
1）筛选符合回填要求的素土作为回填主材，剔除粒径超过规范限值的大块石块、建筑 垃圾，保证回填土有机质含量控制在允许范围内。
2）分层铺填控制每层虚铺厚度不超过300mm，采用12kN 夯击力的振动夯实机对每层土 体进行多遍碾压夯实，边角区域由人工持小型夯实工具补夯。
3）每完成一层回填作业即取样送检，核实压实度指标符合市政道路施工相关规范要求， 检测合格后方可开展下一层回填作业，避免出现漏夯、虚填的质量隐患。
（三）多余土方密闭外运作业实施
作业面回填完成后归集剩余的所有多余土方，统一归集至现场指定的垃圾集中站区域临 时堆放，安排专人对堆土区域进行全覆盖抑尘处理，避免遗撒扬尘影响周边区域环境。
1）选用额定载重10t 的密闭自卸汽车开展外运作业，装车过程中控制装载量不超出车 厢上沿，装车完成后对车厢顶部进行全覆盖密闭遮盖。
2）车辆驶出施工区域前安排专人对轮胎、车身附着的泥土进行全面冲洗，防止带泥上 路污染周边已成型的市政道路路面。
3）所有外运渣土统一运输至政府主管部门指定的消纳点处置，全程留存渣土运输处置 台账，记录每台车辆的外运车次、外运量与消纳地点信息，做到溯源可查，完全符合城市渣 土运输管理相关规定。
（四）土方开挖过程质量安全管控
开挖作业全程安排专职质量员旁站管控，随时复核沟槽底部的标高、宽度与边坡坡度， 采用水准仪与50m 钢卷尺联动校验，避免出现超挖、欠挖或边坡坡度不符合设计要求的问题。
作业区域在行人车辆通行的出入口位置设置硬质隔离防护栏，悬挂明显的警示标牌，严禁无 关人员随意进入开挖作业区域。
配置专职有限空间作业安全员全程盯守作业面，针对部分紧邻老旧电缆沟的开挖区段， 提前探明地下既有管线的走向与埋深，采取人工探挖方式确认管线位置后再开展机械开挖， 防止挖损既有运行管线。沟槽周边设置临时排水沟与集水井，及时抽排作业面内的积水，避 免基底被水长时间浸泡软化引发边坡失稳。
