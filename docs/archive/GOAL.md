# GOAL：施工组织设计 AI 可视化 A3 PDF 工作流

## 已确认合同

【最终状态】
在 `bid-visual-pdf/` 交付一个可在 Pi 中调用的项目级 Skill，将施工组织设计及项目参考资料转换为带工程示意图、精确中文表格和完整溯源记录的 A3 横向 PDF。

【验收 — 全部满足且有证据才算完成】
- `python -m unittest discover -s tests -v` 全部通过。
- `python bidviz.py demo --offline` 成功生成“挖沟槽土方”和“电缆沟”两组 PoC。
- PoC 至少包含位置关系、施工场景、剖面或爆炸图、参数控制、质量安全五类图页中的适用类型。
- 每页 PDF 尺寸为 A3 横向，并输出 4961×3508 的 300 DPI PNG。
- 所有正式参数均可追溯到 `claim_id` 和来源定位。
- 未确认建议、歧义、冲突及缺失单位会阻断 `final` 导出。
- API 客户端支持 `gemini-flash-thinking` 和最多四张参考图，凭据仅从环境变量读取。
- 项目级 Skill、README、示例清单和审查报告齐备。

【不变量 — 任何时候不得违反】
- 不在代码、日志、测试、产物或文档中保存或回显 API key。
- 不把 AI 通用示意图标作现场实景或真实坐标图。
- 不让图像模型生成最终中文、关键数字、尺寸线或正式表格。
- 不静默修复原文歧义、冲突、单位缺失或疑似 OCR 错误。
- 不降低测试、跳过门禁或伪造 API 成功结果。

【边界】
- 允许修改 `bid-visual-pdf/` 目录及其项目级 Skill。
- 不修改工作区其他项目、用户级 Skill 或 Pi 配置。
- 凭据轮换须由用户在供应商后台完成；程序仅检查环境变量。
- 若必须越界，停止并说明理由，等待用户确认。

【迭代策略 — 每轮必须走完这个循环】
1. 运行最小复现或验收命令，记录可重复证据。
2. 更新假设账本中的支持证据、反对证据与状态。
3. 选择能最大区分竞争假设的最小改动。
4. 改动后重跑相关检查，并在阶段结束时重跑完整验收面。
5. 将“假设 → 改动 → 结果 → 下一实验”追加到轮次记录。
6. 不重复已证伪路线；新证据改变方向时，以证据为准。

【停止条件】
- 全部验收项有证据通过时结束，并附命令、产物与残余限制摘要。
- 连续两轮无实质进展或遇到真实 blocker 时停止，列明已尝试路线、证据、原因排序及所需用户输入。

## 执行指示

- 只按上述停止条件终止。

## 轮次记录
### R1
- 假设：现有 Python 图像与 PDF 库足以避免浏览器和 Office 依赖。
- 改动：完成运行环境探测并建立最小 `requirements.txt`。
- 结果：Pillow、ReportLab、PyMuPDF、python-docx、openpyxl、pypdf 均可用，中文字体齐备。
- 下一实验：实现最小数据模型与 A3 单页渲染并运行自检。

### R2
- 假设：文件式 JSON 中间层可支撑 PoC 的事实溯源、图页规划与终稿门禁。
- 改动：实现统一清单、原子事实、问题检测、自适应图页和多参考图 API 客户端。
- 结果：9 项单元测试全部通过；未批准建议和未关闭冲突会阻止 FINAL PDF 输出。
- 下一实验：运行十页 A3 离线图册，核对像素、DPI、PDF 页面尺寸和视觉布局。

### R3
- 假设：Pillow 叠字与 ReportLab 汇编可稳定输出 A3 300 DPI 图册。
- 改动：实现十页 PoC、主视觉完整包含布局、来源脚注、真实性标签和审查报告。
- 结果：离线 PoC 成功生成 10 张 4961×3508 PNG 和 10 页 A3 横向 PDF；自动审计无错误。
- 下一实验：用户轮换新 key 并提供真实总平面图、CAD 导图、节点图和现场照片后，运行在线多参考图 PoC，人工验证几何遵循、伪文字和工程合理性。

### R4
- 假设：PiDeck 生图配置可安全驱动在线 Gemini PoC，且模型能按无字工程提示词输出可用主视觉。
- 改动：增加 PiDeck provider 回退、Gemini 选择、生成审计日志、尺寸线、图例与伪文字检查接口。
- 结果：13 项测试通过；在线生成 10 张主视觉并汇编 10 页 A3 PDF；生成日志不含凭据；自动审计通过；联系表人工检查未见明显伪文字，图页仍标为 DRAFT。
- 下一实验：导入真实总平面图、CAD 导图、节点图和现场照片，验证多参考图几何遵循后由总工签发 FINAL。

### R5
- 假设：执行可在不保存凭据的前提下完成，PiDeck 配置可作为环境变量的安全回退。
- 改动：扫描项目确认无明文密钥；用户确认已在 PiDeck 生图配置中写入新凭据；项目仅读取配置且不写入日志或产物。
- 结果：项目内密钥扫描为零；生成日志凭据字段为零；Gemini 默认模型探测成功。
- 下一实验：以后仅验证配置可调用，不读取或回显凭据内容。

### R6
- 假设：缺少总平面图、CAD、节点图和现场照片时，仍可交付明确标识为通用示意的 PoC，但不能签发项目终稿。
- 改动：位置页改名为“通用空间关系示意”，加强无字提示词，重生十页在线图册，并进行联系表人工审图。
- 结果：13 项测试通过；十页 A3 PDF 自动门禁通过；人工检查未见明显乱码或品牌水印；所有页面保持 DRAFT 与非现场实景声明。
- 下一实验：取得真实项目参考资料后验证几何、节点和现场一致性，再由总工批准 FINAL。
