# bidviz 系统重构任务规划 · V1

> 状态：**待用户确认后执行**。本规划为 V1；整册验收后升 V2（记录实测页数/乱度/成本）。
> 决策来源：2026-10 多轮对话拍板 + `docs/layout-md/layout_classification.md` + `docs/example-image/` 三张样图 + 生图提示词（风格契约来源）。

## 0. 已确认决策（不再讨论）

| # | 决策点 | 结论 |
|---|---|---|
| D1 | 页面规格 | **A3 竖版 297×420mm**（841.89×1190.55pt） |
| D2 | 总路线 | **B 混合**：设计层换新、工程层留旧（管线/缓存/审计/CLI/Web 骨架保留） |
| D3 | 正文政策 | **按类差异**：D/G 全表；A/B/C 保留 1–2 段关键原文与图表同页；H 保留条件句 |
| D4 | 页数预算 | **每节 ≤3 页**（硬约束）；溢出按 调布局→换模板→语义拆分→增页 |
| D5 | 样板节 | **S003（样图同节）+ 文档点名 4 节**（第一章第十一节、第二章第一二节、第四章第三节、第八章第一节） |
| D6 | 产物清理 | **授权删除**（清单见阶段 0.3） |
| D7 | 生图尺寸 | **2K 默认；4K 仅 hero 可选且必须过尺寸校验**（gpt-image-2 4K 会降级到 1536×1086） |
| D8 | 视觉基线 | **样图"工程技术图册风"为唯一基线**；现有报表式演化为 D/G 类表格密集模板，不单独保留 |

补充定性（评估结论，作为本规划的公理）：
- 新体系＝设计层，旧体系＝工程层；重构＝**设计换新 + 工程留旧**。
- 统一骨架：**决策 / 执行 / 验证 三层分离**——设计判断前移到 plan 阶段并冻结；执行是确定性渲染（只吃 tokens + json + 槽位）；质量是可测门禁。
- 分工铁律：**AI 画画面，代码写文字**。图像模型只承担场景/结构/工艺/空间关系；流程/组织/时序/参数/编号/中文一律矢量+真实文字。
- 审计统一口径：**页上文字 ⊆ 原文且可定位**（整段=逐字在 PDF；提炼行=原文前缀在 PDF）。

## 1. 目标架构

### 1.1 决策层（plan-time，落盘可审改，冻结带 version）

| 文件 | 内容 |
|---|---|
| `work/layout-classification.json` | 57 节 × {主类, 辅类[], 内容块[{块名, 类, 槽位序列, 编排注意}], 原起始页}。由 `prompts/classify.md` 半自动生成 → 人工审改 → 冻结 |
| `work/page-plan.json` | 每节 → 页列表；每页 = {template_id, 标题区, KPI[], 图位[任务单], 正文区[原文引用/提炼行], 表格, 溢出记录} |
| `work/issues.json` | {id, 位置, 类型(缺单位/口径冲突/歧义/缺依据), 原文摘录, 建议, 状态(open/confirmed/waived), 决断人, 时间} |
| `work/figure-plan.json`（扩展） | 图位任务单字段：subject/object/composition/must_show/forbid/refs/size_tier/callouts[{no,text,sub,anchor}] |
| `work/source-assets.json` | 47 个 Word 表格 + 60 张内嵌图逐项决策：keep/redraw/replace + 理由 |

### 1.2 执行层（确定性渲染）

| 文件 | 职责 |
|---|---|
| `docs/layout-md/tokens.yaml` | 色板（深海军蓝/浅蓝灰/中性灰/警示红）、字号阶梯、间距阶梯、线宽、组件规格（KPI 卡/编号白片/chevron/图标行/表头）。**模板只引用 token 名** |
| `src/bidviz_templates.py`（新） | 8 类模板 + 组件库：title_block / kpi_strip / figure_with_callouts / prose_column / icon_table / process_strip / chevron_cards / timeline_bar / org_chart / hero_banner / footer_skyline |
| `src/bidviz_vector.py`（扩展） | A3 竖版画布常量与布局区 |
| `src/bidviz_imagegen.py`（新，自 generate_chapter.py 抽出） | style contract + subject 白名单 + 构图契约 + 参考图 + 尺寸校验 + 伪文字检测 |
| `src/bidviz_plan.py`（扩展） | page-plan 生成器、槽位装配、页数预算与溢出算法、prose_policy |

### 1.3 验证层（门禁）

| 门禁 | 实现 | 阻断 |
|---|---|---|
| 乱度逐页 | `src/audit_layout.py`（新）：填充色块数/色种数/左边界离散度，阈值按样图风标定 | 超标页 → DRAFT + 报告 |
| 内容审计 | 现有 `audit_coverage`（口径统一为"页上文字 ⊆ 原文且可定位"） | 缺失 → 阻断 |
| 视觉回归 | 组件固定数据渲染 → 基线 PNG → 像素 diff（Pillow） | 超阈值 → 测试失败 |
| 生图尺寸 | 实际像素 vs 请求档 | 降级 → 重试/换档/降版面用途 |
| 伪文字 | garble-study 方法检测图中文字/乱码 | 命中 → 拒收重生成 |
| issues | open 状态存在 | 阻断 final 或 DRAFT 水印+附录页；waive 必须留痕 |
| 分类抽检 | 每章抽 2 节人工核对主类 | 一致率低于阈值 → 回炉 |

### 阶段 1 · 规格与门禁地基（1.5 天）
- 1.1 `tokens.yaml` 提取（来源=生图提示词视觉段+样图量测）；**签认点①** 人工签认后冻结（带 version）。

### 阶段 2 · 样板页 S003 与签认（2 天）
- 2.1 A3 竖版画布。
- 2.2 实现版式 T-B1（提示词版式）：标题区 → KPI 三区 → 左 55% 图（矢量编号叠标）+ 右 45% 正文 → 底部通栏图标表。
- 2.3 S003 数据装配：KPI=60日历天/3295m(+型号)/1至2天；图位=构图契约+no-text 生图或现有素材；正文按 D3（A 类保留 1–2 段）；表=重点工序实施要点（施工准备/土方与支护/旧通道处理）。

- **验收**：用户肉眼签认；文字可搜索可复制；叠标锚点对位；该页审计 100%。

### 阶段 3 · 分类接入与 8 类模板分批（5–7 天）
- 3.1 `prompts/classify.md` 版本化；生成 `layout-classification.json`（LLM 草案→人工审改→冻结）。
- 3.2 分类抽检门禁（每章抽 2 节）。
- 3.3 `page-plan.json` 生成器：类→槽位序列→页；页数预算 ≤3/节；溢出算法确定性实现。
- 3.4 模板分批：批1 B/C（工艺/构造）；批2 A/D（总览/参数，D=报表式演化）；批3 E/F（时序/组织，矢量图型）；批4 G/H（检验/风险，G=报表式演化，H=风险图+对策表+chevron）。
- 3.5 矢量图型库：process_strip / chevron_cards / timeline_bar / org_chart（纯代码+真实文字）。
- 3.6 build 切换到 page-plan 渲染；旧两页路径保留为 fallback 开关至阶段 7 验收后移除。
- **验收**：文档点名 4 节各出签认页（**签认点③**）；limit 整册跑通；乱度门禁全页过。

### 阶段 4 · 生图侧改造（3–4 天，含生图等待）
- 4.1 `prompts/style.md` 全局风格契约：三语汇映射 8 类（C→等轴测/剖面三维；B→三维施工示意；H→真实感场景；D→不生图）；色板服从 tokens；负面清单（无文字/无编号/无海报光效/无品牌水印）。
- 4.2 figure-plan 任务单字段 + subject 白名单过滤（flow/org/timeline/param 拒收转矢量）。
- 4.3 构图契约 + callouts 锚点数据；生图 prompt 强制 no-text；叠标矢量渲染。
- 4.4 参考图机制：`page-media-map.json` 索引化接入任务单 refs；电缆头三处"同底图+三套标注"落实。
- 4.5 生图门禁：尺寸校验（D7）+ 伪文字检测 → 拒收重试。
- 4.6 风格种子：每类题材 1 张签认（**签认点④**）后冻结为 prompt 前缀+参考图，批量复用。
- **验收**：58 节图位伪文字=0、尺寸达标率 100%、同对象跨节外形一致（人工抽 5 组）。

### 阶段 5 · 原图表决策（2–3 天）

### 阶段 6 · Web 编辑器适配（2 天）

| 乱度反弹（新组件密度高于被否掉的旧版） | audit_layout 逐页门禁 + 组件预算 + 降级链（先丢装饰，KPI/表格永不丢） |
