# bidviz 质量把关手册（用户监督用）

> 用途：用户按本手册对各阶段产出做质量把关、审阅设计方案细节与思路。
> 约定：**每阶段交付三件套** = ①产出清单（文件路径）②自检结果（命令+数值）③待决断项。
> 用户把关动作：看把关物 → 提修改 → 修正后重出样张 → 签认 → 冻结进 `work/frozen.json`（记 sha256，改签认件必须回签）。
> 更新责任：agent 每完成一个阶段更新本手册对应行；决策变化同步 §3 台账。
>
> **配套可视化图册**：`designs/bidviz-quality-gates.fig`（可编辑源稿，12 页） / `docs/bidviz-quality-gates.pdf`（矢量 PDF）。页面顺序：总览 → 系统路线 → G0 → G1 → G2 → G3 → 业务 issues → G4 → 供应商 → G5 → 矢量签认 → 最终路线决策树。

## 六、把关节奏约定（今后执行）

1. **每阶段完成**：agent 交三件套（产出清单/自检数值/待决断项），并在本手册 §一/二 更新状态行。
